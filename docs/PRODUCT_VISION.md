# Vision produit

## Promesse

**TENEBRIS — Le Protocole 9** est un survival horror narratif à la première personne dans lequel une unité spécialisée enquête sur une contamination capable d’apprendre des individus, d’utiliser leurs souvenirs et de transformer les infrastructures d’une ville.

Le jeu associe :

- enquête policière et collecte de preuves ;
- exploration oppressante ;
- survie tactique aux ressources contenues ;
- horreur psychologique fondée sur les voix, les souvenirs et la perception ;
- environnements voxel cinématographiques ;
- récit fortement mis en scène.

## Identité graphique

Le voxel n’est pas un raccourci de production ni une référence à un jeu de construction. Il constitue le langage visuel du projet.

Les piliers visuels sont :

1. volumes cubiques détaillés et irréguliers ;
2. proportions humaines crédibles ;
3. matériaux physiques : béton humide, métal, verre, poussière et matière organique ;
4. éclairage cinématographique, brouillard volumétrique et contrastes rouge/cyan ;
5. contamination capable de modifier visiblement les surfaces et les structures ;
6. interface tactique propre à l’UFST et au Protocole 9.

## Expérience recherchée

Le joueur doit se sentir compétent mais jamais tout-puissant. Son équipement lui permet d’observer, d’analyser et de survivre ; il ne transforme pas le jeu en shooter à vagues.

La peur doit venir en priorité de :

- ce que le joueur croit avoir entendu ;
- la possibilité qu’une voix alliée soit imitée ;
- la transformation progressive d’un lieu déjà visité ;
- l’incertitude concernant l’état réel d’un humain ;
- l’impression que la Souche comprend ses habitudes.

## Principes non négociables

- Le récit et le gameplay se servent mutuellement.
- Aucun texte interne de développement n’apparaît dans une version joueur.
- Aucun système n’est ajouté uniquement pour augmenter artificiellement la durée.
- La lisibilité, l’accessibilité et la stabilité passent avant la quantité de contenu.
- Les prototypes restent internes ; les versions présentées sont finies selon leur périmètre.
